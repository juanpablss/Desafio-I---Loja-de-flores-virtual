Flora Encanto - Simulador de Compras

Projeto: Simulador de Compras - Floricultura Virtual Aluno: Juan Pablo Trilha: Desenvolvimento mobile

Sobre a loja

A Flora Encanto é uma floricultura virtual fictícia. Ela vende buquês e arranjos de flores para várias ocasiões, como aniversários e datas especiais.

Produtos e preços:

Buquê de Rosas: R$ 59,90

Buquê de Girassóis: R$ 49,90

Buquê de Tulipas: R$ 69,90

Tecnologias usadas:

HTML

CSS

JavaScript

Como executar:

Deixe os arquivos index.html, style.css e script.js na mesma pasta.

Abra o arquivo index.html no navegador.

Clique no botão "Simular compra".

informe a quantidade desejada para cada produto.

Testes realizados

Compra com 2 rosas, 1 girassol e 0 tulipas: total de R$ 169,70.

Todas as quantidades iguais a 0: mostra que nenhum produto foi selecionado.

Número negativo: mostra mensagem de erro.

Letras no lugar de número: mostra mensagem de erro.

Clicar em "Cancelar": a simulação é encerrada.
